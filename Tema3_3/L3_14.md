## 1. Введение: Почему тестирование файлового ввода-вывода — это сложно

Файловый ввод-вывод — это одна из самых распространённых зависимостей в приложениях. Чтение конфигураций, запись логов, обработка пользовательских файлов, экспорт и импорт данных — всё это требует взаимодействия с файловой системой.

**Основные проблемы при тестировании файлового ввода-вывода:**

| Проблема | Описание |
|----------|----------|
| **Побочные эффекты** | Тесты создают файлы, которые остаются на диске |
| **Загрязнение окружения** | Тесты могут случайно удалить или перезаписать важные файлы |
| **Неизолированность** | Одни тесты влияют на другие через общие файлы |
| **Ошибки доступа** | Тесты могут падать из-за отсутствия прав на запись |
| **Медленная работа** | Работа с реальным диском медленнее, чем с памятью |
| **Невоспроизводимость** | Состояние файловой системы разное в разных окружениях |

**Решение:** Использовать **временные директории** (`tmp_path` в pytest), которые создаются для каждого теста и автоматически удаляются после его завершения.

## 2. Фикстура `tmp_path` — основной инструмент

### 2.1. Что такое `tmp_path`

`tmp_path` — это встроенная фикстура pytest, которая создаёт **уникальную временную директорию** для каждого теста.

**Ключевые характеристики:**

| Свойство | Описание |
|----------|----------|
| **Изоляция** | Каждый тест получает свою собственную директорию |
| **Автоматическая очистка** | Директория удаляется после завершения теста |
| **Кроссплатформенность** | Работает на Windows, Linux, macOS |
| **Безопасность** | Использует системную временную директорию (обычно `/tmp` или `%TEMP%`) |
| **Возвращаемый тип** | `pathlib.Path` (объект, поддерживающий современный API) |

import json
from pathlib import Path

class ConfigManager:
    def __init__(self, config_dir):
        self.config_dir = Path(config_dir)
        self.config_dir.mkdir(parents=True, exist_ok=True)
    
    def save(self, name, data):
        file_path = self.config_dir / f"{name}.json"
        with open(file_path, 'w') as f:
            json.dump(data, f)
    
    def load(self, name):
        file_path = self.config_dir / f"{name}.json"
        if not file_path.exists():
            raise FileNotFoundError(f"Config {name} not found")
        with open(file_path, 'r') as f:
            return json.load(f)
    
    def delete(self, name):
        file_path = self.config_dir / f"{name}.json"
        if file_path.exists():
            file_path.unlink()

            reader = csv.DictReader(f)

Pytest предоставляет две фикстуры для временных директорий:

5.2. tmp_path vs monkeypatch для файловой системы
Инструмент	Когда использовать
tmp_path	Тестирование реальных операций с файлами
monkeypatch	Подмена функций open, os.path.exists и др. (когда не нужно создавать реальные файлы)
Рекомендация: В большинстве случаев используйте tmp_path вместо мокирования ФС. Это проще и надёжнее.

5.3. tmp_path vs pyfakefs
Инструмент	Преимущества	Недостатки
tmp_path	Простой, встроенный, реальная ФС	Требует прав на запись
pyfakefs	Полная изоляция, не касается реальной ФС	Сторонняя библиотека, медленнее

Фикстура tmp_path — это универсальный и надёжный инструмент для тестирования файлового ввода-вывода в pytest.

Директория автоматически удаляется после завершения теста.

Всегда проверяйте, что файлы действительно создаются и имеют правильное содержимое.

python
import os
import json
import shutil
from pathlib import Path
from datetime import datetime

class FileManager:
    def __init__(self, base_dir):
        self.base_dir = Path(base_dir)
        self.base_dir.mkdir(parents=True, exist_ok=True)
    
    def save(self, filename, data):
        file_path = self.base_dir / filename
        with open(file_path, 'w') as f:
            json.dump(data, f)
        return file_path
    
    def load(self, filename):
        file_path = self.base_dir / filename
        if not file_path.exists():
            raise FileNotFoundError(f"File {filename} not found")
        with open(file_path, 'r') as f:
            return json.load(f)
    
    def list_files(self, pattern="*"):
        return [f.name for f in self.base_dir.glob(pattern) if f.is_file()]
    
    def delete(self, filename):
        file_path = self.base_dir / filename
        if file_path.exists():
            file_path.unlink()
    
    def create_backup(self, filename):
        file_path = self.base_dir / filename
        if not file_path.exists():
            raise FileNotFoundError(f"File {filename} not found")
        
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        backup_name = f"{filename}.{timestamp}.backup"
        backup_path = self.base_dir / backup_name
        shutil.copy2(file_path, backup_path)
        return backup_path
    
    def get_file_info(self, filename):
        file_path = self.base_dir / filename
        if not file_path.exists():
            raise FileNotFoundError(f"File {filename} not found")
        stat = file_path.stat()
        return {
            "size": stat.st_size,
            "created": datetime.fromtimestamp(stat.st_ctime),
            "modified": datetime.fromtimestamp(stat.st_mtime),
            "is_file": file_path.is_file(),
        }
    
    def cleanup_old_backups(self, days=7):
        cutoff = datetime.now().timestamp() - (days * 24 * 60 * 60)
        for file_path in self.base_dir.glob("*.backup"):
            if file_path.stat().st_mtime < cutoff:
                file_path.unlink()
    
    def move_to_subdir(self, filename, subdir):
        src = self.base_dir / filename
        if not src.exists():
            raise FileNotFoundError(f"File {filename} not found")
        
        dest_dir = self.base_dir / subdir
        dest_dir.mkdir(exist_ok=True)
        dest = dest_dir / filename
        shutil.move(str(src), str(dest))
        return dest
